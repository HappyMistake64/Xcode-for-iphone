04 / DEVICE INSTALLATION

Podpis vyžadován

GitHub Actions vrátí nepodepsanou IPA a ZIP aplikace. Soubor IPA můžeš předat legitimní podpisové službě. Bez podpisu a provisioning profilu ji iOS nenainstaluje.

Alternativou je Apple Developer Program, TestFlight nebo Xcode Personal Team (vyžaduje Xcode a obnovování podpisu). Přímá instalace bez těchto podmínek není podporována.
